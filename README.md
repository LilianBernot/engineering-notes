# Engineering Notes

A collection of technical blog posts and engineering notes on AI/ML architecture, distributed systems, and software engineering practices.

## Structure

- `/posts/` - Published blog posts (format: `YYYY-MM-DD-title.md`)
- `/drafts/` - Work in progress posts
- `/templates/` - Templates for new posts

## Topics

- AI/ML Architecture & Design Decisions
- Model Context Protocol (MCP)
- Distributed Systems
- Software Engineering Best Practices
- Technical Trade-offs & Architecture Patterns

## Writing Guidelines

- Posts should be dated and follow the format: `YYYY-MM-DD-title.md`
- Include metadata at the top (title, date, tags)
- Focus on general engineering principles rather than company-specific details
- Use clear code examples and diagrams where helpful
